# drafts —— 未成文的草稿区

这里放**还没打算成篇**的东西，与 `articles/` 的区别是：`articles/` 里的文章
必须有完整且合法的 Front Matter，进入构建流水线；而本目录的内容不参与构建。

## 存放规则

| 位置 | 放什么 |
|---|---|
| `ideas.md` | 零散想法、选题清单、一句话灵感。不追求格式 |
| `unfinished/` | 已经动笔但还不能称为文章的内容，可以没有 Front Matter |

## 与 articles/ 的边界

- 内容一旦决定认真写，就用 `inloop new` 在 `articles/<年份>/` 下建正式目录，
  然后把素材迁过去，**不要**在这里长期养着一篇实质上的长文。
- 本目录的内容**不会被 `inloop check` 校验**，也不会被构建。想让它被检查，就说明它该进 `articles/` 了。
