# config —— 配置

本目录是所有可调参数的**唯一事实源**（任务书 §2、§20）。

| 文件 | 管什么 |
|---|---|
| `site.yaml` | 站点信息与品牌配色（名称、作者、主色等） |
| `wechat.yaml` | 微信公众号渲染参数（字号、行高、标题样式、图片阈值等） |

## 存放规则

- **只放配置数据，不放代码。** 读取逻辑在 `src/inloop/config.py`。
- **改配置不需要改代码。** 构建脚本每次运行都重新读取本目录。
- **禁止在代码里再写一份同样的默认值。** 两处定义必然漂移；缺键时程序应当报错并指出缺少哪个键，而不是偷偷用一个代码里的默认值。
- 新增配置项时，同时更新任务书 §20 与本目录的注释说明，保持文档与配置一致。
