# styles —— 样式事实源

本目录保存排版与配色的**唯一文字出处**，任务书 §9.3、§10 的设计规则以注释形式
写在文件里，改样式时依据与实现一起改。

| 文件 | 管什么 |
|---|---|
| `wechat.css` | 微信公众号正文字体、字号、行高、标题、引用、代码块、表格、图片 |
| `code.css` | 代码块的语法着色 |

## 与构建产物的关系（重要）

产物**不允许外链 CSS**（任务书 §9.2），最终 HTML 只允许 inline style。
因此本目录的角色是「源」而不是「引用目标」：

```text
styles/*.css  ──解析──▶  选择器→声明 映射  ──写入──▶  每个元素的 style 属性
```

## 两条硬约束

1. **只使用元素/后代选择器**，不要给元素加 class。产物要求零 class：
   class 在粘贴后可能被丢弃，且会成为编辑器样式重写的突破口。
2. **禁止依赖 JavaScript、外部 CSS、复杂选择器、iframe**，也不要引入
   只在浏览器里成立的效果（伪元素、CSS 变量注入到产物、媒体查询等）。

## 尺寸单位

正文排版一律用 `px`。微信编辑器会改写相对单位，用 `em`/`rem` 会导致比例错乱。
