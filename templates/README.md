# templates —— 文章模板

`inloop new` 创建文章时，从这里按 `--template` 指定的名字取模板作为正文骨架
（任务书 §6、§7.1）。

| 文件 | 用途 | 适用 category |
|---|---|---|
| `article.md` | 通用文章 | 不限 |
| `paper-note.md` | 论文拆解 | `paper` |
| `build-log.md` | 实验日志 | `build` |
| `research-note.md` | 研究随想 | `research` |
| `diary.md` | 科研生活，模板最轻 | `diary` |

## 存放规则

- 一个模板一个文件，文件名即 `--template` 的取值（不带 `.md`）。
- 模板里的 Front Matter 用占位符，由 `inloop new` 填入真实值；
  占位符写法将在实现 `new` 时于本文件与任务书 §6 同步确定。
- **模板只管结构，不管样式。** 版式与配色属于 `styles/`，不要写进模板。
