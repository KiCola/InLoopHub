# assets —— 仓库级共享素材

这里放**跨文章共用**的素材。与 `articles/<年份>/<slug>/assets/` 的区别：
后者只服务某一篇文章，前者被多篇文章或 README 共用。

```text
assets/
├── brand/    品牌标识：logo.png、logo-no-text.png、avatar.png
├── covers/   通用封面底图、封面模板背景
└── common/   其他共用素材（表情、示意图、示意图零件等）
```

## 存放规则

- **能就近就就近。** 只有确实被多篇文章引用时，才放进本目录；单篇配图放回文章自己的 `assets/`。
- 文件名用英文小写加连字符，如 `logo-no-text.png`，不要出现中文文件名或空格。
- 大体积素材（> 3MB）不要提交，构建时会给出 WARNING。仓库体积是被长期抱怨的头号问题。
- 二进制素材一旦提交就不要反复替换同名文件，Git 会永久保留每一版；需要迭代时用新文件名。
