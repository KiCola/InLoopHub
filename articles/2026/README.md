# 2026 年文章

按任务书 §3 的约定，文章按年份分目录，每篇文章一个独立目录。

```text
2026/
├── 001-hello-inloop/
│   ├── index.md
│   ├── cover.png
│   └── assets/
└── 002-light-o1/
    ├── index.md
    ├── cover.png
    └── assets/
```

## 目录命名

`<三位序号>-<英文 slug>`，例如 `002-light-o1`。

- 序号在**全仓库范围内**唯一且递增，用于稳定排序，不随年份重置。
- slug 只用小写字母、数字和连字符。
- 目录名一旦发布就不要改：它同时也是构建产物目录名与文章定位标识。
